# Đo trang chủ Duolingo máy tính (ảnh thầy gửi 07/11, 2000 × 1357)

Tỉ lệ ảnh ≈ 1,45: vạch thanh bên ở x = 370, thanh bên Duolingo rộng 256px. Đơn vị ở bảng dưới là px CSS = điểm ảnh / 1,45. Khung nhìn tương ứng ≈ 1379px.

| Phần | Điểm ảnh | px CSS | Áp vào app HS (≥ 1240) |
|---|---|---|---|
| Thanh bên: rộng / vạch phải | 0–370 / 3 | 256 / 2 | 256, vạch phải 2px --tr-vien |
| Mục điều hướng: cao | 128–206 | 54 | 54 |
| Mục điều hướng: lề ngoài | x 15 | ~10 | đệm thanh 16 |
| Mục điều hướng: bo / viền chọn | ≈ 18 / 3 | 12 / 2 | 12 / 2px --tr-hs |
| Mục: biểu tượng / khe tới chữ | 43 / 34 | 30 / 23 | 30 / 20 |
| Mục: chữ (cao chữ hoa) | 15 | 10,3 ⇒ 15px 700 IN HOA | 15 / 700, giãn .8px |
| Bước giữa hai mục | 89,5 | 62 = 54 + 8 | khe 8 |
| Cột giữa (dải xanh): x / rộng | 436–1320 | 300 / 610 | ≤ 610 |
| Khe thanh bên → cột giữa | 66 | 45 | 48 |
| Khe cột giữa → cột phải | 71 | 49 | 48 |
| Cột phải (thẻ) rộng | 1391–1940 | 379 | 320–380 |
| Lề phải | 60 | 41 | 48 |
| Thẻ phải: viền / bo / đệm trong | 3 / ≈ 22 / 30 | 2 / 15 / 21 | thẻ phẳng của app (bo 20) |
| Khe giữa hai thẻ | 24 | 17 | 20 (giữ) |
| Đỉnh cột giữa / cột phải | 62 / 128 | 43 / 88 | 32 (hàng chào trải 2 cột) |

Dưới 1240px (máy tính bảng ngang 1180, Fold 1104 × 884 và 884 × 1104, điện thoại ngang): nếu vẫn đặt thanh 256 thì cột giữa còn dưới 500px, chật. Duolingo cũng thu thanh bên dưới khoảng 1160px. Vì vậy khổ này giữ ray biểu tượng 76px như cũ, hai cột 1fr / 1fr.
